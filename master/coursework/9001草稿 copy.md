这款游戏的灵感来源于澳大利亚的国鸟鸸鹋。它不会飞，但是我在游戏里面设计它可以飞过障碍。

首先我们可以看到开始界面是我自己生成的艺术字。背景是悉尼大学的草坪和蓝花楹，它每次拍翅膀的时候都会播放鸸鹋振翅的声音，值得注意的是，每一次开始产生的小鸟都是随机的。

接下来就到了系统的主要运行部分，我们需要按空格键，或者上箭头来保证小鸟不会落到地面，或者碰到障碍物，屏幕的正上方的数字表示它成功跨越的障碍数。

如果碰到障碍，游戏就会结束，结束界面会有提示。如果你按照提示做的话，会回到游戏的开始界面，重新开始游戏。

再开始一遍游戏，我们会发现背景发生了变化，小鸟也发生了变化。这就是我设置的随机生成。

下面来到代码部分，我主要用了Pygame 库作为核心框架，同时配合 Python 自带的 sys、os、random 和 itertools 标准库。我们可以看到Pygame 负责实现图像渲染、音效播放、动画更新、键盘输入、碰撞检测等所有游戏核心功能，是整个程序的运行引擎；sys 用于控制程序退出；os 用于处理文件与资源路径，让模块导入和图片加载更灵活；random 让小鸟颜色与管道高度等元素具有随机性；itertools 用于实现小鸟拍翅动画的循环切换

This game is inspired by the emu, the national bird of Australia. It cannot fly, but I designed it to fly over obstacles in the game.

First, we see the start interface with artistic text that I created myself. The background is the lawn of the University of Sydney and blue-flowered cypress trees. Every time the bird flaps its wings, it plays the sound of an emu flapping its wings. The bird generated each time is random.

Next comes the main operation part of the system. We need to press the space bar or the up arrow key. This ensures that the bird will not fall to the ground or touch obstacles. The number displayed at the top of the screen shows the number of obstacles it has successfully crossed.

If you hit an obstacle, the game ends. There will be a prompt message on the end screen. You can follow the prompt to return to the game's start interface. Then you can start the game again.

When you start the game again, we will find that the background has changed. The bird has also changed. This is the random generation function I set up.

Next is the code part. I mainly use the Pygame library as the core framework. I cooperate with Python's sys, os, random, and itertools standard libraries.

We can see that Pygame is responsible for all the core functions of the game. These functions include image rendering, sound effect playback, animation updates, keyboard input, and collision detection. Pygame is the running engine of the entire program.

sys is used to control program exit. os is used to handle files and resource paths. This makes module imports and image loading more flexible. random makes elements such as bird color and pipe height random. itertools is used to realize the loop switching of the bird's wing-flapping animation.
